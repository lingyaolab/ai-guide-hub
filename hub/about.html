关于这个 Hub

只做导航、选型与索引，不复制正文。

维护原则：教程库各自在自己的仓库里独立版本、独立部署；Hub 通过固定 URL 链接过去。 任何一套更新，不需要动另外四套。

如果某个教程链接 404，通常是该仓库还没开启 GitHub Pages；先看对应仓库的 README， 或改 hub/assets/data.js 里的 site 字段。

来源与边界

所有教程都强调「回到源码」。

  • 页面上的数字、默认值、抛错点尽量带 file:line 出处。
  • 版本固定在各自的主版本；升级时先跑对应仓库的 check-sources 与 samples。
  • Hub 的跨站搜索索引由各仓库的 nav.js 生成，不抓取正文。
  • 如果某个链接失效，先看对应仓库的 README 与部署状态。
