三个选型问题

答完基本能确定先读哪一套。

1. 你的服务已经在 Spring 里吗？

是 → 先看 Spring AI；不是 → 继续下一问。

Spring AI 的优势是自动装配与 Advisor，代价是绑定 Spring 生态。

2. 你需要显式状态与暂停恢复吗？

需要 → LangGraph 或 AgentScope 的 State / Session；不需要 → 普通 Chain 或 Agent 就够了。

如果只需要工具循环，普通 Agent 就够了，不必上状态图。

3. 团队主要用 Java 还是 Python？

Java 平台 → AgentScope Java；Python 多 Agent → AgentScope Python。

语言之外，还要看部署、观测和团队现有的运维体系。

选型时先看项目缺哪一层，而不是比功能多少。 先写清楚你需要的是 ChatClient、工具循环、RAG、状态恢复还是服务托管， 再对照上表找到合适的一行。不同框架可以互相借鉴，但一个项目里最好只保留一套运行时。
